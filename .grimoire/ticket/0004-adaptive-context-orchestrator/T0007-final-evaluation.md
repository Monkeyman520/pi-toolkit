### Accounting and continuity

Per-run audits reconcile the full persisted session tree with completed-message events as a multiset and inspect every HTTP attempt's last cumulative usage frame. P1's four failed transmissions have no usage. P2's final attempt 96 reported 96,853 partial tokens before a native 120-second stream-stall error: its positive metadata does not certify complete output or final charges. The audit explicitly invalidates full-run totals while retaining that subtotal and original raw result.

No real trial launched children or decision/compaction models. Their incremental model-call counts are genuinely zero within these paired windows; ordinary parent context, tools, commands and local I/O still cost resources. The production observer's active-branch report is not substituted for whole-run accounting. SDK/catalog dollar values are not invoices.

P1 adaptive has three native retry omissions targeting failed assistant responses, not ACO unloads. P2/P3 have zero persisted context edits. There were zero context-edit recovery attempts/failures or in-task human steering in these trials; controlled executor tests separately demonstrate actual recovery. Mistake accounting distinguishes **one infeasible P2 composition proposal**, **zero harmful ACO edits observed**, and **unestablished counterfactual utility**. No ordinal success or causal gain is inferred from missing data.

## Fixes discovered and final source boundary

Production fixes were independently regression-driven, not copied from model artifacts: require registered provider before reservation; fail closed and explicitly repair interrupted tool exchanges using verified originals/legal anchors; treat failed SDK zero defaults/legacy failed-child budget flags as unknown; reject failed/aborted parent admission even with positive partial usage. Raw records/reservations remain retained. Successful reported zero is compatible. P3 measured a frozen candidate **before** the last positive-partial admission refinement; final production gates exercise the later combined tree.

Remaining **limitations, not proved defects**: heuristic/declared demand and estimated lengths; no general paraphrase proof, multi-turn autonomous children, OS spending sandbox, complete invoice/cache attribution, broad-platform certification or statistically proved cost/quality advantage. Observed native socket/stall/startup failures do not establish their underlying cause. Native user/peer work is not governed by ACO.

## Final process-scoped proxy verification

The final user instruction applies to subsequent tests, not retroactively to frozen trials. Test-only `ACO_TEST_PROXY=http://127.0.0.1:7890` supplies HTTP(S)/ALL proxy variables, explicit local bypasses and Node env-proxy support without forwarding arbitrary credential-bearing proxy URLs or changing global settings. Credential-free nested verification retains only this selected routing.

Actual isolated Pi (Bun 1.4.4, embedded Node API 26.3.0) made an unauthenticated HEAD request, returned expected 404, and owned an **ESTABLISHED TCP connection to 127.0.0.1:7890**. No inference was sent. Final runtime gates run serially with that environment; a proxy cannot diagnose or guarantee prevention of local startup pauses. Local proof: `proxy-pi-proof.json`; final command receipt: `final-proxy/gates.json`. These do not replace earlier failed runs.

Raw manifests, result/audit/verification JSON, traces and complete archives are retained locally under `T0007-artifacts/`, with archive hashes in `completed-archives.json`. The Markdown receipts are the portable repository evidence; raw JSON/tarballs are not published.
